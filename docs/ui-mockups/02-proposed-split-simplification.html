Split with friends — simplifying the per-friend amount control

Today each friend row has a Custom checkbox that reveals a separate amount field only once checked. Proposed: drop the checkbox, always show one amount box per friend - empty shows a placeholder reading "Equal" rather than sitting blank, so the state is visible rather than something to infer. Typing a number makes that friend's share custom instead; nothing in the domain logic (ComputeSplit) changes, since a blank/placeholder box already means exactly what customAmount = null means today.

  • Option A - just the toggle removal. Smaller, no open design questions, ready to build now.
  • Option B - the same, plus a per-friend Settled chip, surfacing TransactionSplitRepository.settle() which already exists but has no UI anywhere today. Needs a decision first: editing a split today wholesale-replaces every split on save, which would wipe settled state - shown here so you can see the shape of it before we decide how that interaction should work.
